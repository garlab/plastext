# Native M2 preview

Read **bold text**, *emphasis*, ~~strikethrough~~, `inline code`, café, and &amp; entities.
Use `⌘F` to find “bold text”, then Enter to visit the match. `⇧⌘V` toggles Source.

## Navigation

[Jump to the table](#table), [open the CSV](sample.csv), [open the SVG](sample.svg),
or [read the specification](../specs.md#markdown).
Headings appear in the outline (`o`) and symbol picker (`⇧⌘O`).

> [!NOTE]
> This is a read-only preview. Editing and task toggles arrive in M3.
